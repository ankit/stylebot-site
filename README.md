# stylebot-site

Source for [stylebot.dev](https://stylebot.dev/), the website of the [Stylebot](https://github.com/ankit/stylebot) browser extension, and [gallery.stylebot.dev](https://gallery.stylebot.dev/), its gallery of styles people publish. Both are built with [Astro](https://astro.build/): stylebot.dev is static HTML with a few Preact islands (the hero demo, theme menu and logo), and the gallery is a Preact app.

- [Development](docs/development.md): running and building both sites
- [The extension](docs/extension.md): the wording and screenshots borrowed from the extension's repo
- [Deployment](docs/deployment.md): publishing stylebot.dev and the gallery, and launching the gallery
